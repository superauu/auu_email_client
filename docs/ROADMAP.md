## 下一阶段 A：真实数据与通用收发闭环

1. 已完成：Rust repositories、Windows 系统凭据服务、桌面 MailGateway 与分页查询 IPC。
2. 已完成：IMAP / SMTP 隐式 TLS 验证、账号向导与真实账号持久化。STARTTLS / 仅收信与连接重配已接入。
3. 已完成 IMAP INBOX / Sent UID 分批增量同步及进程内多账号调度；网络无 DB 锁，支持去重、排队取消和独立手动重试。A3.8 增加多目录 / 历史、持久任务 / 退避、运行中停止、IDLE / MODSEQ、原文重取和附件另存为。
4. A4.1 已完成：SQLite 本地草稿、自动保存、并发版本核对与退出保护；发送队列、撰写附件与安全 HTML 渲染未完成。
5. 验收：至少两个真实账号，收信 / 回复 / 发信 / 重启恢复 / 离线阅读；发送结果不明时不重复发送。

同步锁与调度 A3.2、邮件状态 A3.3、主动恢复 A3.4、跨代 / 分页 A3.5 已完成。A3.6 新增可信原定位下的完整原文指纹补齐及超过 50000 候选的区间分段 / 全段集合复核，见 REMOTE_RECOVERY。A3.7 增加库前 IMAP 流式硬限额、密集邮箱固定小区间、大检查点锁外序列化和失败保留，见 IMAP_LIMITS。无可信原定位和原文时不伪造历史证据。A3.8 收尾范围与自动检查见 IMAP_COMPLETION / STATUS：增加受限大邮件下载、缓存 / 附件、多目录 / 历史、删除复核 / 跨目录明确恢复、自动续页、持久调度 / 退避 / 停止、IDLE / CONDSTORE、Google / Microsoft OAuth 配置与重配。真实账号和大邮箱性能仍待验收；目录 CRUD / 任意移动 / 永久删除、keywords、QRESYNC、服务器草稿上传、前端虚拟化另行实施。接下来完成授权账号验收，再推进 SMTP / outbox，先明确未知发送结果语义。

## 阶段 B：提供商兼容

Microsoft Graph、Gmail API、POP3 / SMTP；IMAP OAuth 刷新代码已接入，真实提供商兼容仍需验收；在开发初期并行推进应用注册与测试账号配置（这里指工作安排，不要求使用多代理）。保留提供商标签、会话和文件夹原始语义。

验收：每条路径有真实测试账号；重新授权、管理员限制、权限撤销、游标失效、已发送副本和账号隔离都有实际验证。

## 阶段 C：管理与 AI

标签 CRUD、搜索保存、规则、本地事件 / 提醒、ICS；AI 服务配置、摘要、生成回复草稿、提取待办。随后增加日历双向同步。

验收：从邮件整理到事件、生成回复再确认发送形成闭环；无用户授权不上传；AI 文本不能直接执行操作。

富文本、附件预览、中文搜索优化、虚拟列表、可调整字号、备份恢复、数据库升级、可访问性审核、macOS / Linux 验证、签名和更新。
