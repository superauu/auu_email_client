# UI 基础与约定

## 设计方向

延续 AuuGit 的桌面工作区：稳定分栏、低干扰表面、细分隔线、克制强调色。邮件客户端阅读区铺满整个窗格，内容从左侧起（不使用网页式居中窄栏），正文优先，账号身份始终可辨认。默认 Paper，提供 Graphite 与 Linen 验证不同风格。

界面布局：62px 顶栏 / 62px 活动栏 / 190–320px 可调导航栏（默认 222px，双击分隔条复位；1250px 以下固定 204px 并隐藏分隔条）/ 280–900px 可调邮件列表（默认 340px，双击复位）/ 自适应阅读区 / 28px 状态栏。1250px 以下适当压缩；960px 以下列表和阅读切换；桌面窗口最小 900×640。浏览器最低支持宽度为 720px，目前不做手机端。

## 样式边界

- 共享结构和状态在 `src/styles/index.css`；未来按 feature 拆分时仍使用同一语义变量。
- 皮肤值来自 `src/themes/contract.ts`，具体值只写在皮肤 JSON；业务 UI 不写十六进制颜色。
- 背景层次使用 canvas / surface / surface-raised；交互使用 surface-hover / surface-selected。
- 文本分 text / text-muted / text-subtle；accent 只用于主要操作、选中和焦点。
- 状态使用 danger / success / warning。账号与标签使用主题相对的 teal / blue / amber 语义类；名称和图标一同表达，不只依靠颜色。
- Tailwind 已接入语义颜色映射，可使用 `bg-background`、`text-foreground`、`border-border`。不混入第三方硬编码配色。
- 模型输出、邮件 HTML、皮肤资源都不能向应用主界面注入 CSS 或 HTML。

## 排版与间距

字体为本地打包 Inter Variable（正文）与 Orbitron Variable（品牌展示字，与 AuuGit 同源；仅用于拉丁品牌词 "AuuMail"，中文回退 Segoe UI / Microsoft YaHei UI / 系统 sans-serif），不从 CDN 请求字体。默认正文 13px、约 2 倍行高；标题 20–27px；列表内容 11–12px；辅助信息 9–11px。重要信息不能仅放在最小字号中。字号可调整和可读性增强是后续任务。

间距采用 4 / 8 / 12 / 16 / 24 / 32px 基础节奏。圆角、控件高度和邮件行高由皮肤规定；布局宽度和交互行为属于应用，不由皮肤重写。长主题、地址和正文必须截断或换行，不得撑破分栏。

## 共享组件

| 组件 | 规则 |
| --- | --- |
| Button | primary / secondary / ghost；默认 type=button；提交必须显式 type=submit |
| Dialog | Radix Portal、遮罩、Title / Description；焦点限制、Esc 与焦点归还；未保存数据由业务拦截 |
| Avatar | 主题相对颜色；配套可见账号或联系人名称 |
| EmptyState | 标题、原因、可选实际操作；区分没有数据与没有搜索结果 |
| ResizeHandle | 指针拖动、左右方向键、Home / End；双击恢复默认宽度；拖拽期间锁定光标并禁止文本选择 |
| ErrorBoundary | 捕获渲染错误，提供恢复入口，不输出可能含邮件内容的错误日志 |

新组件先判断是否可扩展现有基础。共享组件不读取邮箱 store。暂不引入 shadcn 配置或第二套组件体系；当前是直接使用 Radix。

## 状态与交互

- 邮件列表同时覆盖 unread、selected、hover、starred；取消星标后正确更新筛选结果。
- 定位恢复区区分正在核对、待确认、仍在源、歧义、失败、过期及已恢复；先展示证据与远端位置，明确确认时再核对。普通同步完成不表示归档已确认；核对本身不直接移动，重新排队归档必须是独立的明确操作。
- 分页核对显示 checked / total / matches，部分结果即使一个匹配也不出现确认按钮；确认阶段需要分页时仍显示继续入口，不把进度当成恢复成功。网络失败可从已提交页面继续；跨代绑定明确提示新 UIDVALIDITY 与完整原文指纹要求。
- 指纹补齐使用独立的核对 / 确认按钮，缺少可信原定位时禁用并说明原因，不显示指纹已补齐。大范围进度区分“分段正文核对”和“全段集合复核”，收集阶段的候选数不是全局完成比例；全段完成前不得确认绑定。
- 任何账号切换都保留账号隔离；回复默认使用原账号，撰写页明确展示发件人。
- 搜索为空显示对应空状态；没有内容时不保留上一账号邮件详情。
- 已读 / 星标 / 归档在本机保存成功后更新界面，保存期间禁用重复控件；失败保留原状态并显示错误。区分本机已保存、等待回写、失败、冲突和结果未知；unknown 归档不自动重试，详见 MESSAGE_CHANGES。草稿保存失败保留输入，不清空编辑器。
- 撰写停止输入 800ms 后自动保存；保存期间允许继续编辑，最新内容未保存前不显示成功。保存失败保留输入。
- 撰写关闭时先自动保存，失败才展示保存 / 放弃 / 继续编辑兜底；未修改空白撰写直接关闭。浏览器离页请求 beforeunload 确认。强制结束进程不保证未落盘输入恢复，详见 DRAFTS。
- 发送按账号 capabilities.send 与桌面环境开放，演示 / 仅收信账号禁用并说明；登记 outbox 不等于已投递。撰写地址、抄送密送与格式交互见 COMPOSING。AI 面板标明未启用，不生成假结果。
- 设置账号页的发送队列展示全部未发送任务与最近 128 条已发送记录，提供账号 / 状态筛选。queued 可取消，明确 failed 可重试或返回原草稿，sending 等待；unknown 与 keep-local 保持独立安全出口。按任务禁用在途操作，失败不移除记录，长错误换行；返回草稿不替换其他正在编辑的内容。
- 交互要有成功、失败、等待状态。不要只显示一个没有后续行为的按钮。
- 同步按账号显示排队 / 运行 / 完成 / 失败 / 已取消。排队可取消，运行中提交停止请求并显示正在停止，直到 worker 退出；不把请求接受当作停止完成；失败账号可重试，其他账号操作不应一起禁用。支持同步全部，演示账号不入队。
- 关闭设置后同步继续；进度保存在 App 层，不保存在设置弹窗局部状态。完成后的后台刷新不卸载阅读 / 撰写界面，不覆盖期间新保存的草稿。长错误信息在账号卡片内换行。

快捷键：Ctrl / Cmd + K 聚焦搜索，N 新建邮件（输入框或弹窗内不触发），Esc 关闭弹窗（未保存修改会拦截）。Tab 遍历可操作控件；邮件列表采用原生 button 行为。

## 可访问性与视觉检查

- 图标按钮有 aria-label；选中、展开或切换状态使用 aria-current / aria-pressed 等语义。
- 所有输入有 label；状态和错误使用 status / alert；不要清除全局 focus-visible。
- 保留系统缩放，尊重 reduced-motion 和 forced-colors。新增动效不影响信息可达性。
- 桌面选择策略：应用框架（导航、列表、工具栏、状态栏）不响应文本选择；阅读区、事件视图、关于信息与输入框保留选择。拖动分隔条不得产生选区。
- 新皮肤需检查文本、焦点和主要操作的对比度。当前并未声称通过完整 WCAG 审核。
- UI 改动至少检查 1440×950、900×700，三皮肤 × 明暗模式；检查长正文、空结果、弹窗、键盘操作、横向溢出。
- 截图用于人工检查，行为测试用于验证操作；不把生成截图等同于已经看过截图。

## IMAP 当前入口

同步设置按账号独立，加载失败可关闭重开，保存失败保留选项；默认自动 / 历史关闭。OAuth 等待、验证、提交、保存 / 失败 / 取消要区分，committing 不可误报取消，回到工作区必须刷新真实本机结果。仅收信时 SMTP 明确未验证，不显示成功。

POP3 使用同一单账号 / 全部同步入口；设置只提供自动间隔，不展示 IMAP 多目录 / 历史选项。连接重配保留 POP3 协议，端口 / 加密 / 验证结果以 POP3 标注，仅开放 TLS 直连；明确保留服务器副本和本机标记边界。

服务器目录以原始 ID 筛选，账号切换清除 folderId；不可用目录仍可读缓存。远端草稿显示服务器副本，复制为新本地 ID，不覆盖原邮件。附件另存为取消无成功提示，失败可重取原文；未知位置不可直接下载 / 写回。自动续页不开放提前确认，located 仍需明确确认并完整重查。

## 标题栏与紧凑邮件列表（2026-11-11）

标题栏品牌 / 空白区域处理左键 mousedown：detail=2 切换最大化，否则调用原生拖动；搜索框及其 label、按钮、链接等交互区域不启动窗口操作。Tauri 调用集中 platform，静态加载窗口 API，避免按下后才下载模块延误拖动。参照 [Tauri 窗口文档](https://v2.tauri.app/learn/window-customization/)，不可同时绑定原生 data-tauri-drag-region 和手动事件而重复切换。

邮件列表采用 Outlook 式紧凑三行：发件人 / 日期、主题、摘要；移除大收件箱标题、宣传文字和账号介绍。44px 工具栏提供全部 / 未读真实筛选和日期排序说明，屏幕阅读器仍能读到当前文件夹 / 数量。统一账号视图在右侧显示账号，标签详情留在阅读区 / 悬停说明。Paper / Graphite / Linen 默认 76 / 72 / 80px，长文本截断，保留未读点、选中和独立星标。

未读视图打开邮件并标已读后，列表移除该结果但阅读区保留正在阅读的邮件，不突然跳到下一封；切换账号或文件夹重新核对范围，不展示前一个账号内容。

列表和阅读区工具栏统一 44px，底部分隔线必须对齐；邮件列表首选宽度最大 900px，ResizeObserver 依据实际邮件区动态收紧上限并预留 320px 阅读区及 5px 分隔条。窗口收窄不覆盖保存的宽度，放宽后恢复原首选值；960px 以下沿用列表 / 阅读切换。分隔条 ARIA 范围和当前值应反映实际显示宽度。


## 常用入口与账号目录树（2026-11-15）

左栏采用常用快捷入口 + 可折叠账号目录树，见 NAVIGATION。标准目录与服务器目录只表达一次所属关系；多同类实际目录仍按 ID 区分，本机 / 服务器草稿明确标注。常用快捷入口显示所属账号，固定按钮在悬停和键盘焦点时可见，取消固定不删除目录。

展开箭头和账号选择是独立按钮，折叠不改变当前筛选；选中态核对完整导航目标。真实账号优先、演示账号独立分组；普通徽标为未读数，草稿 / 星标显示各自数量。切换范围保留未读筛选，窄窗口返回邮件列表。文件夹长名称截断并提供完整悬停名称，不撑破侧栏。

## 多选操作栏（2026-11-20）

多选时保持 44px 工具栏：左侧固定取消选择与数量徽标，右侧固定已读 / 归档 / 删除图标与「更多操作」，在最小 280px 列表宽度下完整显示，不使用横向滚动。图标均提供可访问名称与悬停说明；数量过长时截断并保留完整 title，处理中显示进度且禁用操作。

次要操作（未读、添加星标、同账号移动、废纸篓永久删除）放入共享 Radix DropdownMenu；移动使用子菜单，Portal 避免分栏裁剪，长目录换行。保留方向键、Esc 和焦点归还；取消菜单不取消已选邮件。永久删除保留明确确认。背景、徽标、菜单与危险操作状态只使用皮肤语义 token。
