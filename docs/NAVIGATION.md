## 使用方式

- 常用默认显示全部收件箱、跨账号星标邮件和跨账号本机草稿。账号目录右侧图钉可固定 / 取消固定，最多 30 项；快捷入口显示所属账号，移除快捷入口不删除邮件或目录。
- 点击账号名称进入该账号收件箱并展开目录，旁边独立箭头仅折叠 / 展开，不改变当前阅读范围；按钮支持键盘操作。切换范围清除搜索与标签，保留列表的全部 / 未读筛选。
- 桌面工作区只显示用户添加的真实账号，包括离线和需要重新授权的账号；全部收件箱、星标、本机草稿、搜索、标签与统计均限定在这些账号内。没有真实账号时显示添加邮箱入口，不回退演示数据。浏览器预览独立使用演示 gateway。
- 标准目录用中文显示，同类只有一个实际目录时不再重复列出 INBOX / Drafts / Deleted Messages 等原名。悬停可查看原目录名称。自定义目录以原显示名称列在所属账号内，不擅自按路径标点猜测 IMAP 层级。
- 同类实际目录有多个时，保留不同 folderId，并以「中文名称 · 原目录名」区分，不能为了减少导航行而合并它们。不可用目录保留缓存阅读入口，并标「不可用」。
- 本机草稿与服务器草稿分开：前者有可编辑 draft 元数据，只写本机；后者是服务器副本，编辑要复制为新的本机草稿。没有服务器草稿目录或缓存时，不凭空显示服务器草稿行。
- 归档保留本机意图视图，未确认的 MOVE 不会让已本机归档的邮件消失；标准收件箱等目录遵守本机归档意图。存在多个远端归档目录时，另保留各自实际目录入口。自定义目录按真实缓存 membership 展示，便于核对。

## 状态与存储

- 普通目录及账号旁的数字表示缓存内未读数；星标显示星标邮件数，草稿显示草稿数。悬停说明统计含义；列表底部显示当前筛选结果总数，不把缓存数量称作服务器总量。
- 固定项和展开状态存 `auumail.ui.navigation.v1`，只包含导航目标 / 账号 ID，不存邮件正文、账号凭据或目录显示名称。损坏偏好回退默认；保存失败保留当前会话选择并显示提示。
- 不属于当前工作区账号的旧固定项不显示，偏好原数据保留；当前账号内失效的目录固定项显示提示并可移除，不猜测新 folderId 或跳转到其他账号。账号切换与常用跳转一次性携带 accountId / folderId / mailbox / draftSource，选中态跟随完整目标。
- `MailQuery.draftSource` 仅为前端缓存筛选字段，不改变 IPC、数据库、同步队列和服务器目录。新入口仍经 store / gateway，不在业务组件直接访问文件系统或网络。

桌面启动不再调用演示种子初始化或旧演示草稿导入。历史演示账号、邮件、草稿与偏好仍留在原存储，不删除或改写；gateway 在分页读取时携带真实 accountId，并在返回共享快照前过滤所有集合。无 accountId 的历史全局标签只在真实邮件使用时展示，有真实账号归属的标签可以为空。

## 验证与边界

领域测试覆盖标准目录映射、多同类目录保留、账号隔离、物理 membership 与简化 mailbox 区分、本机 / 服务器草稿、unknown 归档意图及坏偏好。浏览器测试覆盖固定 / 移除 / 重载、独立折叠、键盘操作、中文映射与真实目录 ID、长名称、旧库演示数据隔离、无账号引导和三皮肤明暗模式。

暂无常用拖拽排序、服务器目录创建 / 重命名 / 删除、目录层级元数据，以及本机草稿上传。原始目录 ID 和缓存数据不因导航重排而改写。
