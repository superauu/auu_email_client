# IMAP 收信与同步收尾验收

更新至 2026-11-16，A3.8。本单七项代码路径已实现并有脚本 / 本机数据库回归；真实 Gmail 授权、刷新、全目录同步、SMTP 基础发送、自发自收附件下载与回复会话归组已验收。真实 POP3、独立抄送密送与其他客户端仍待验收，另有中文附件名严格 MIME 参数兼容问题待修，见 STATUS / SENDING。Graph / Gmail API、AI、日历与发布仍属于独立路线，不把本单完成称为全部 IMAP 标准与服务商差异均已实现。

## 固定安全约束

不以 Message-ID / 解码正文推断跨代身份；弱历史哈希和原文重取观察不自动升级可信来源。恢复仍单候选 1 MiB / 页 10 MiB，不能跳过过大候选；全部 collecting + validating、明确确认重新扫描、generation / revision CAS 保留。最多 128 可访问目录，源目录不可访问时不猜重命名。未知归档不盲目重发 MOVE。

自动同步默认关闭；新建 / 升级真实账号默认全部文件夹，历史默认关闭。自动续页需用户点击，首次只读检查到 located 必停；确认后继续完整重扫才绑定。自动续页不是自动授权恢复 / 发信。

## 未验收及后续独立工作

1. Gmail 已完成真实授权、刷新和全目录同步；仍需补真实 FLAGS / MOVE、断线 / 撤销 / ACL、限流与其他服务商目录差异验收。Microsoft 应用未注册且入口禁用；通用 IMAP / STARTTLS 的真实兼容验收继续保留。
2. 真正五万封以上、稀疏 UID、高延迟 / 持续变化邮箱性能与内存基准；当前协议脚本不等同吞吐压测。UI gateway 仍加载全部分页快照，虚拟列表 / 按视图加载尚未做。
3. 不提供服务器目录 CRUD / 重命名、任意 MOVE、永久删除 / EXPUNGE、keywords / Gmail 原生标签、QRESYNC 或服务器草稿 APPEND。服务器草稿可收取 / 复制为本地草稿，本地草稿不会上传。
4. 完整原文和附件解码仍可能占用最高 64 MiB 原文之外的解析内存，512 MiB 仅缓存配额；不承诺进程 RSS。原文超限明确失败，不跳过 UID。HTML 清洗 / 沙箱和撰写附件发送已实现；附件预览与正文图片发送未实现。Gmail 小附件真实下载字节往返已验收；大附件、其他客户端与中文文件名严格参数兼容问题见 STATUS。
5. 系统 DNS / TLS 阻塞可能延迟停止，IDLE 仅监测 INBOX；其他目录定时核对。没有跨目录事务快照、歧义副本人工选择、不可访问目录猜测恢复。
6. 2026-11-16 发送队列 / POP3 设置及手动入队已完成原生 WebView 重点路径检查（独立本机合成资料、真实 Rust / SQLite，见 STATUS）；真实 POP3 服务器成功验收仍未执行。Chromium IPC harness、本机缺失凭据和连接拒绝均不代替远端成功验收。安装包、跨平台凭据 / 文件对话框及发布验收仍需独立完成。
